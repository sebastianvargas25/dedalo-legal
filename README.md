# dedalo-legal

Páginas públicas (soporte y política de privacidad) de la app **Dédalo**,
operada por SyJ Company. Publicadas con GitHub Pages para la ficha de la
App Store / Play Store.

- `soporte.html` — URL de soporte
- `politica-privacidad.html` — URL de política de privacidad

El contenido canónico vive en `docs/` del repositorio `dedalo-app`; este repo
solo lo publica. No reutiliza `buildersdock-legal` (marca anterior).
